## 1. Export Overview & Formats

PRIVGUARD AI supports three export formats for compliance documentation and audit submissions:
- **`ZIP` (Verifiable Package - Recommended):** A self-contained, cryptographically signed audit bundle containing canonical JSON records, artifacts, checksums, the public verification key, and an independent verification script.
- **`JSON` (Consolidated):** A single structured JSON document containing the signed manifest, executive summary, control definitions, and sanitized evidence records.
- **`CSV` (Spreadsheet):** A flattened tabular export designed for ingestion into Governance, Risk, and Compliance (GRC) tools such as Archer, ServiceNow GRC, or internal compliance trackers.

## 3. Defense-in-Depth Sanitization Guarantees

Before writing any artifact or field to an export bundle, the `sanitize_payload()` pipeline executes:
1. **Key Denylisting:** Any dictionary key containing `password`, `secret`, `private_key`, `raw_key`, `api_key`, or `bearer` is immediately overwritten with `[REDACTED_SENSITIVE_CREDENTIAL]`.
2. **Regex Scanning:** Any string matching common token or key patterns (`sk-...`, `pg_live_...`, `AKIA...`, `BEGIN PRIVATE KEY`, etc.) is scrubbed and replaced with `[REDACTED_CREDENTIAL]`.
3. **Tenant Scoping:** The export queries the database strictly under the active user's `tenant_id`, guaranteeing cross-tenant isolation.

## 4. Independent Verification Procedure (Without PRIVGUARD Access)

An auditor can independently verify the package on any standard workstation with Python 3.8+ and the standard `cryptography` package.

### Step 1: Extract the Archive
```bash
unzip privguard_compliance_export_*.zip -d audit_package/
cd audit_package/
```

### Step 2: Verify Artifact Checksums
Confirm that the SHA-256 digest of each file matches the entry recorded in `manifest.json`:
```python
import hashlib, json

with open("manifest.json", "r") as f:
    manifest = json.load(f)

for path, expected_hash in manifest.get("artifact_hashes", {}).items():
    with open(path, "rb") as f:
        actual_hash = hashlib.sha256(f.read()).hexdigest()
        assert actual_hash == expected_hash, f"Integrity failure in {path}!"
print("All artifact checksums VERIFIED.")
```

### Step 3: Verify the Ed25519 Manifest Signature
```python
import json
from cryptography.hazmat.primitives.asymmetric import ed25519
from cryptography.hazmat.primitives import serialization

# 1. Load Public Key
with open("public_key.pem", "rb") as f:
    public_key = serialization.load_pem_public_key(f.read())

# 2. Load Manifest and extract signature
with open("manifest.json", "r") as f:
    manifest = json.load(f)

sig_hex = manifest.pop("signature")
sig_bytes = bytes.fromhex(sig_hex)

# 3. Canonicalize manifest dictionary (RFC 8785)
canonical_bytes = json.dumps(manifest, sort_keys=True, separators=(",", ":")).encode("utf-8")

# 4. Verify signature
try:
    public_key.verify(sig_bytes, canonical_bytes)
    print("AUDIT MANIFEST SIGNATURE: VALID")
except Exception as e:
    print(f"AUDIT MANIFEST SIGNATURE: INVALID ({e})")
```
